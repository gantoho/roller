requestAnimationFrame

每帧回调计算 offset += speed × deltaTime， 通过 transform: translateX(offset % originalSize) 驱动。 主线程每帧参与计算，精确控制每一帧位置。

📊 技术特性对比

特性 CSS Transition CSS Animation requestAnimationFrame
动画线程 合成器线程（GPU） 合成器线程（GPU） 主线程（CPU）
暂停/恢复 需手动记录位置+剩余时间 animationPlayState（天然支持） cancel/requestAnimationFrame
速度变化 需重新计算 duration 需替换 @keyframes 即时生效（改变 speed 变量）
页面不可见时 继续运行（浪费性能） 继续运行（浪费性能） 自动暂停（rAF 行为）
每帧开销 几乎为 0（CSS 引擎处理） 几乎为 0（CSS 引擎处理） JS 回调 + DOM 写入
循环连续性 setTimeout 回调 snap 回 0 animation infinite 自动循环 取模映射，理论上最平滑
