InfiniteRoller API 文档

rAF CSS Transition CSS Animation 三个类共享完全相同的公共 API，仅构造函数名不同

1. 快速开始

<!-- HTML: 将需要滚动的元素直接放入容器 -->
<div id="myRoller">
    <div class="item">公告 1</div>
    <div class="item">公告 2</div>
    <div class="item">公告 3</div>
</div>

<script src="infinite-roller.js"></script>
<script>
const roller = new InfiniteRoller(document.getElementById('myRoller'), {
    direction: 'horizontal',
    gap: 20,
    speed: 50,
});
</script>
三个类：InfiniteRoller（rAF）、InfiniteRollerTransition、InfiniteRollerAnimation。 除核心动画引擎不同外，构造函数参数、方法、回调完全一致，替换类名即可切换。

2. 构造函数

2.1 参数

new InfiniteRoller(container, options)

new InfiniteRollerTransition(container, options)

new InfiniteRollerAnimation(container, options)

参数类型必需说明
containerHTMLElement是滚动容器元素，其 overflow 将被设为 hidden
optionsObject否配置项对象，见下方

2.2 配置项

选项类型默认值说明
direction string 'horizontal' 滚动方向：'horizontal' | 'vertical'
gap number 20 每项之间的间距（px），通过独立 margin 实现
speed number 50 滚动速度（像素/秒）
autoStart boolean true 是否在初始化后自动开始滚动
pauseOnHover boolean true 鼠标悬停时是否暂停滚动
minCloneMultiplier number 3 最小克隆倍数，轨道总长至少为原始尺寸的 N 倍
contentInsufficient string 'scroll' 内容总尺寸小于容器尺寸时的策略：
  • 'scroll' — 继续滚动，自动克隆填满容器
  • 'stop' — 停止滚动，内容居中显示
scrollThreshold number 0 滚动触发阈值（px）。内容 ≥ 容器 - 阈值×2 时触发滚动，确保两侧保留阈值间距
scrollThresholdFromGap boolean false 若为 true，scrollThreshold 自动取 gap 的值
gapBreakpoints Object null 响应式断点配置，见下方 gapBreakpoints
infoElements Object null 自动更新状态元素，见下方 infoElements
cloneIdSuffix boolean true 克隆元素时是否自动给 id 添加唯一后缀避免冲突
resizeDebounceMs number 100 resize 防抖间隔（毫秒）

2.3 rAF 专属配置项

以下选项仅对 InfiniteRoller（rAF 版）有效：

选项类型默认值说明
stepMaxRatio number 0.5 单帧最大步长占原始尺寸比例，防止切后台后跳跃
precisionThreshold number 1e8 偏移量超过此值时主动取模，防止浮点精度丢失
maxDeltaTime number 0.05 单帧最大时间差（秒），防止切后台后的超大步长

3. 回调钩子

回调类型触发时机
onPlayFunction调用 play() 时
onPauseFunction调用 pause() 时
onDestroyFunction调用 destroy() 时
onRefreshFunctionrefresh() 完成时（含初始化和 resize）
onResizeFunctionresize 触发、refresh() 调用之前
 
const roller = new InfiniteRoller(container, {
    onRefresh() {
        console.log('刷新完成，当前内容宽度:', this._getContentWidth());
    },
    onResize() {
        // 可在 refresh 前动态调整配置
        this.options.speed = window.innerWidth < 600 ? 30 : 50;
    },
});

4. gapBreakpoints — 响应式断点

根据窗口宽度自动调整间距。格式：{ 阈值: 间距, default: 兜底间距 }。

const roller = new InfiniteRoller(container, {
    gapBreakpoints: {
        600: 6,      // 窗口宽度 ≤ 600px 时 gap = 6px
        1024: 16,    // 窗口宽度 ≤ 1024px 时 gap = 16px
        default: 30, // 其他情况 gap = 30px
    },
});
断点按阈值升序匹配，找到第一个 窗口宽度 ≤ 阈值 即停止。若都不匹配则使用 default。

5. infoElements — 自动更新状态元素

通过 CSS 选择器指定 DOM 元素，库会自动更新其文本内容（无需手动操作 DOM）。

<!-- HTML -->
<span id="gapVal"></span>
<span id="statusVal"></span>
<span id="originVal"></span>
<span id="containVal"></span>

<script>
const roller = new InfiniteRoller(container, {
    infoElements: {
        gap:     '#gapVal',      // 当前 gap 值
        status:  '#statusVal',   // 当前状态文本
        origin:  '#originVal',   // 原始内容尺寸
        contain: '#containVal',  // 容器尺寸
    },
});
</script>
键自动更新的值
gap当前 gap 值（如 "20px"）
status"⏸ 已停止，内容居中" 或 "▶ 正常滚动" 或 "⏳ 测量中…"
origin原始内容尺寸（如 "450px"）
contain容器尺寸（如 "800px"）

6. 实例方法

6.1 play()

roller.play()

开始滚动。若内容不足且 contentInsufficient: 'stop'，则不会启动。

6.2 pause()

roller.pause()

暂停滚动，保留当前位置。

6.3 stop()

roller.stop()

停止滚动并重置位置到起点。

6.4 refresh()

roller.refresh()

刷新组件：重新读取内容布局、重新计算克隆份数、更新居中状态。适用于窗口 resize 或动态增删内容后调用。

库内部已自动监听 ResizeObserver + window.resize，通常无需手动调用。

6.5 destroy()

roller.destroy()

销毁组件：停止动画、移除事件监听、断开 ResizeObserver、还原 DOM 结构。

7. 实例属性（只读）

属性说明
roller.container滚动容器 DOM 元素
roller.track内部滚动轨道 DOM 元素
roller.originalItems原始子元素数组（非克隆）
roller.originalSize原始一份内容的总尺寸（px）
roller.containerSize容器可视区尺寸（px）
roller.isPlaying是否正在播放
roller.destroyed是否已销毁
roller.options当前配置对象（可修改）

8. 完整示例

<div id="roll">
    <div class="item">🎯 公告一</div>
    <div class="item">📢 公告二</div>
    <div class="item">🔔 公告三</div>
</div>
<button onclick="roller.pause()">暂停</button>
<button onclick="roller.play()">播放</button>
<span id="status"></span>

<script src="infinite-roller.js"></script>
<script>
const roller = new InfiniteRoller(document.getElementById('roll'), {
    direction: 'horizontal',
    gap: 24,
    speed: 60,
    pauseOnHover: true,
    contentInsufficient: 'stop',
    scrollThresholdFromGap: true,
    infoElements: { status: '#status' },
    onRefresh() {
        console.log('内容宽度:', this.originalSize, '容器宽度:', this.containerSize);
    },
});
</script>
