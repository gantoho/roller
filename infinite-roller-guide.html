InfiniteRoller 使用文档

通用无限循环滚动组件 — 三种动画引擎可选，API 统一，无缝无闪烁

一、简介

InfiniteRoller 是一个轻量级、无依赖的 JavaScript 无限循环滚动组件，提供 三种动画引擎实现，共享完全相同的公共 API，仅核心动画技术不同：

版本类名JS 文件动画引擎适用场景
rAF InfiniteRoller infinite-roller.js requestAnimationFrame 需要精确控制 / 频繁变速
Transition InfiniteRollerTransition infinite-roller-transition.js CSS Transition 匀速滚动 / 低功耗设备
Animation InfiniteRollerAnimation infinite-roller-animation.js CSS @keyframes 最简单实现 / 暂停恢复频繁

三个版本可通过 多份 DOM 克隆 + 取模偏移映射策略，保证视觉完全无缝无闪烁。替换类名即可切换引擎，无需修改任何配置代码。

特性说明
无依赖纯原生 JS，无需 jQuery / lodash 等第三方库
GPU 加速使用 translate3d，仅触发合成层，不触发布局重排
完全无缝独立 margin + 多份克隆 + 取模偏移，无任何闪烁或跳跃
双向支持水平 horizontal / 垂直 vertical 方向
全面可配所有行为均可通过 options 配置，提供合理默认值
自动适配内置 ResizeObserver，窗口缩放自动重排

二、快速开始

2.1 引入文件

根据需求选择一种动画引擎：

<!-- rAF 引擎（推荐，需要精确控制） -->
<script src="infinite-roller.js"></script>

<!-- 或 CSS Transition 引擎（合成器线程驱动） -->
<script src="infinite-roller-transition.js"></script>

<!-- 或 CSS Animation 引擎（声明式，暂停恢复最简单） -->
<script src="infinite-roller-animation.js"></script>

2.2 编写 HTML 结构

容器内的直接子元素即为滚动内容项：

<div id="myRoller" class="scroll-container">
    <div>🎯 前端架构</div>
    <div>🚀 高性能动画</div>
    <div>⚡ 无限循环滚动</div>
    <div>🎨 CSS 硬件加速</div>
    <div>📦 智能复制拼接</div>
</div>

2.3 初始化

const roller = new InfiniteRoller(
    document.getElementById('myRoller'),
    {
        direction: 'horizontal',
        gap: 20,
        speed: 60,
        autoStart: true,
        pauseOnHover: true,
    }
);

2.4 基本样式参考

.scroll-container {
    overflow: hidden;    /* 容器必须隐藏溢出 */
    width: 100%;
    background: #fff;
}
.scroll-item {
    flex-shrink: 0;      /* 防止 flex 压缩子项 */
    white-space: nowrap; /* 水平滚动时保持不换行 */
    padding: 0.8rem 1.5rem;
    border-radius: 12px;
    text-align: center;
}
提示：容器 CSS 中的 overflow: hidden 是必需的，组件内部也会自动设置。 组件的轨道会使用 display: flex + will-change: transform，无需额外设置。

三、配置项

以下配置项对三个版本均生效（标注 rAF 专属 的除外）。

配置项类型默认值说明
direction string 'horizontal' 滚动方向：'horizontal'（水平） / 'vertical'（垂直）
gap number 20 每项之间的间距（px）。使用独立 margin 实现，克隆时自动继承
speed number 50 滚动速度（像素/秒）
autoStart boolean true 初始化后是否自动开始滚动
pauseOnHover boolean true 鼠标悬停时是否暂停滚动
contentInsufficient string 'scroll' 内容总尺寸小于容器尺寸时的处理策略：
'scroll' — 继续滚动，自动复制内容填满容器
'stop' — 停止滚动，内容居中显示
scrollThreshold number 0 滚动触发阈值（px）。内容 < 容器 - 阈值×2 时停止，>= 时滚动，确保两侧保留阈值间距
scrollThresholdFromGap boolean false 若为 true 且未显式设置 scrollThreshold，则自动取 gap 的值
gapBreakpoints Object null 响应式间距断点配置，如 { 600: 6, 1024: 16, default: 30 }。
key 为窗口宽度阈值（px），value 为对应 gap 值。default 键为兜底值。
infoElements Object null 自动更新状态 DOM 元素，如 { status: '#el', origin: '#el', contain: '#el', gap: '#el' }。
每次 refresh 后自动更新对应元素的 textContent。
minCloneMultiplier number 3 最小克隆倍数，轨道总长至少为原始尺寸的 N 倍
resizeDebounceMs number 100 窗口 resize 的防抖间隔（毫秒）
cloneIdSuffix boolean true 克隆元素时是否自动给 id 属性添加唯一后缀，避免页面内 id 冲突
stepMaxRatio rAF 专属 number 0.5 单帧最大步长占原始尺寸的比例。防止切换浏览器后台回来后画面跳跃
maxDeltaTime rAF 专属 number 0.05 单帧最大时间差（秒），防止切后台后超大步长
precisionThreshold rAF 专属 number 1e8 偏移量超过此值时主动取模，防止浮点精度丢失
onPlay Function null 开始滚动时的回调函数，this 指向实例
onPause Function null 暂停滚动时的回调函数
onDestroy Function null 销毁时的回调函数
onResize Function null resize 触发 refresh 前调用，this 指向实例。适用于在 refresh 前动态调整配置
onRefresh Function null refresh 完成后调用，this 指向实例

四、API 方法

方法说明
.play() 开始滚动。如果 contentInsufficient === 'stop' 且内容不足，则禁止滚动并自动忽略
.pause() 暂停滚动，保持当前位置
.stop() 暂停滚动，并将位置重置到起点
.refresh() 刷新组件。重新测量尺寸、重新克隆、重置偏移。适用于容器尺寸变化或内容动态增删后调用
.destroy() 彻底销毁组件。清除所有事件监听、断开 ResizeObserver、还原 DOM 到初始状态

五、典型场景

5.1 水平跑马灯（内容充足，自然滚动）

const roller = new InfiniteRoller(document.getElementById('myRoller'), {
    direction: 'horizontal',
    gap: 24,
    speed: 60,
    autoStart: true,
    pauseOnHover: true,
    contentInsufficient: 'stop',   // 内容充足时用 stop 更合理
});

5.2 垂直滚动公告栏（内容很少，强制滚动）

const roller = new InfiniteRoller(document.getElementById('noticeBar'), {
    direction: 'vertical',
    gap: 16,
    speed: 40,
    autoStart: true,
    contentInsufficient: 'scroll', // 内容不足也继续滚动，自动填满
    minCloneMultiplier: 4,         // 内容少时可以增加克隆倍数让滚动更流畅
});

5.3 图片轮播（手动控制）

const roller = new InfiniteRoller(document.getElementById('carousel'), {
    direction: 'horizontal',
    gap: 0,                       // 图片之间不需要间距
    speed: 80,
    autoStart: false,             // 不自动开始，由按钮控制
    pauseOnHover: false,
    contentInsufficient: 'stop',
});

// 按钮控制
document.getElementById('playBtn').onclick = () => roller.play();
document.getElementById('pauseBtn').onclick = () => roller.pause();

5.4 响应式间距 + 自动状态显示（gapBreakpoints + infoElements）

new InfiniteRoller(document.getElementById('myRoller'), {
    direction: 'horizontal',
    speed: 60,
    gapBreakpoints: { 600: 6, 1024: 16, default: 30 },  // 小屏6px, 中屏16px, 大屏30px
    infoElements: {
        gap: '#gapDisplay',      // 自动显示当前间距 "30px"
        status: '#statusDisplay', // 自动显示 "▶ 正常滚动" 或 "⏸ 已停止"
        origin: '#originDisplay',
        contain: '#containDisplay',
    },
});

5.5 内容不足居中（contentInsufficient: 'stop' + scrollThreshold）

new InfiniteRoller(document.getElementById('myRoller'), {
    direction: 'horizontal',
    gap: 20,
    speed: 50,
    contentInsufficient: 'stop',      // 内容不足时停止滚动
    scrollThresholdFromGap: true,     // 触发阈值自动取 gap 值 20px
    // 或者手动设置: scrollThreshold: 20,
    infoElements: { status: '#status' }, // 自动显示 "⏸ 已停止，内容居中" 或 "▶ 正常滚动"
});

5.6 动态添加内容后刷新

// 向容器添加新内容
const newItem = document.createElement('div');
newItem.className = 'scroll-item';
newItem.textContent = '🔥 新项目';
document.getElementById('myRoller').appendChild(newItem);

// 刷新组件，它会自动重新捕获所有子项并重建克隆
roller.refresh();

六、生命周期管理

在单页应用（SPA）中，务必在组件销毁时调用 destroy() 释放资源：

const roller = new InfiniteRoller(container, options);

// 页面离开或组件卸载时
function cleanup() {
    roller.destroy();  // 清除事件监听、ResizeObserver、还原 DOM
}

// Vue3 示例
onBeforeUnmount(() => { roller.destroy(); });

// React 示例
useEffect(() => {
    return () => roller.destroy(); // 清理函数
}, []);

七、原理概述

InfiniteRoller 的核心滚动机制分为四步：

  1. 轨道构建：将容器的直接子元素移入一个内层轨道（div.infinite-track），轨道使用 display: flex 布局
  2. 间距处理：不采用 CSS gap 属性（因为 gap 在克隆组边界会有间距突变），而是给每个子项单独设置 margin-right（水平）/margin-bottom（垂直），克隆时样式自动继承，边界间距完全一致
  3. 多份克隆：将原始内容克隆 N 份（默认 N=3），拼接在轨道末尾。轨道总长 = 原始尺寸 × N，保证取模回绕时视口内始终有连续内容
  4. 偏移递增 + 取模映射：scrollOffset 单调递增、永不重置。每次渲染时 effectiveOffset = scrollOffset % originalSize，应用 translate3d(-effectiveOffset, 0, 0)。因为有多份克隆，偏移跨越一个 originalSize 时用户无感知

动画驱动使用 requestAnimationFrame，每帧根据时间差 delta 累加偏移量：

// 伪代码示意
function animationLoop(now) {
    delta = Math.min(maxDeltaTime, (now - lastTimestamp) / 1000);
    scrollOffset += speed * delta;          // 偏移递增
    effective = scrollOffset % originalSize; // 取模映射
    track.style.transform = `translate3d(-${effective}px, 0, 0)`;
    requestAnimationFrame(animationLoop);
}

八、常见问题

Q1: 滚动看起来卡顿怎么办？

检查是否有其他 JS 动画或高频 DOM 操作阻塞主线程。可以尝试降低 speed 值， 或确保滚动项数量合理（不要过多克隆，minCloneMultiplier: 3 通常足够）。

Q2: 内容不足时我不想要滚动，就静止展示，怎么做？

设置 contentInsufficient: 'stop'。此时内容总尺寸小于容器尺寸时，组件不会克隆任何副本，直接停止滚动。

Q3: 窗口尺寸变化后滚动位置不对了？

组件内部已通过 ResizeObserver 监听容器尺寸变化并自动调用 refresh()。 如果遇到特殊情况，也可以手动调用 roller.refresh() 强制重建。

Q4: 克隆的元素 id 冲突怎么办？

默认会开启 cloneIdSuffix: true，克隆时自动为 id 属性添加 _clone_xxxx 后缀。 如果你的元素不需要 id，也可以关闭此功能节省一点性能。

Q5: destroy 后想重新启用？

destroy() 是不可逆操作。重新启用需要新建 new InfiniteRoller(container, options) 实例。
